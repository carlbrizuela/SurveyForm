# 📋 Survey Form Project
A simple **Survey Form** built using **HTML** and **CSS**. 

## Description
This project collects user responses to questions related to their physical fitness through various input types like text fields, radio buttons, checkboxes, and dropdown menus.

## Technologies Used
* HTML
* CSS

## Live Demo
- Please click this [link](https://carlbrizuela.github.io/SurveyForm/) to view project.

## Installation and Setup
1. Clone the repository: `https://github.com/carlbrizuela/SurveyForm.git`
2. Open the `index.html` file in your preferred web browser.
